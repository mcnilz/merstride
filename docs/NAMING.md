# Naming decision

Accepted by the user on 2026-11-15: **Merstride**, CLI spelling `merstride`.

Rationale: suggests Mermaid plus stride through a process. It avoids generic Flow/Agent combinations and does not imply an official Mermaid product. Suggested description: “A native execution engine for Mermaid workflows in Markdown.”

Status: selected for this project; not registered or reserved externally. Exact searches for “Merstride”, GitHub-scoped searches, package-index-scoped searches (NuGet, npm, crates.io, pkg.go.dev), and “Mer Stride” software/tool variants returned no exact indexed project/package match in this research. Both available search engines were used across the candidate screening. Search coverage is incomplete; this does not establish registry availability, domain availability, trademark clearance, or absence of phonetic confusion.

GitHub repository names are scoped to an owner. No owner was supplied, so availability of owner/merstride has not been checked. Before publishing, check that exact owner/repository path, registry endpoints if packages are planned, and relevant trademark registers. No name, domain, account, or package was registered.

Other candidates screened: Merrun had existing commercial-name uses; Merstep had existing non-software uses; Merrow-derived names have an existing software-studio association. Merstride was selected following this limited screen.

The accepted naming is applied throughout this package:

This is a pre-release naming decision, not a migration from a shipped product. No legacy executable or format aliases are required.
