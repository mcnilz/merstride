Merstride 0.1.0 release candidate

Offline sequential Markdown workflow execution. Mermaid defines graph edges;
constrained YAML defines process, existing-agent and terminal behavior. Run
`merstride guide --json` for the protocol. Explicit absolute state roots allow
resumption from another directory. No LLM integration or runtime download.

This source snapshot is not release-qualified. Required clean Windows 11 x64 and
Linux x64 and macOS 15+ arm64 no-.NET suite evidence and the same-agent token-benefit experiment must
be supplied for the exact source commit and native hashes before publication.
The release gate refuses missing evidence. SDK/WSL or hosted SDK checks do not
prove a clean target. Detached child termination and physical disk failure are
outside the execution contract. Linux host glibc/ICU requirements apply.

The manifest records source commit, workflow run, RID, SDK/toolchain and test
identity. Archives contain MIT and complete runtime third-party notices;
third-party components retain their own licenses. Build tooling is separate.
