# P17 live console activity

P20 supersedes the activity wording/identity layout. P24 adds concurrent process
output to the text streams. See [ADR 0016](0016-p20.md) and [ADR 0019](0019-p24.md).
The persistence, stream, live visibility and no-replay guarantees below remain.

Extend P13's presentation with a CLI-only decorator of the existing
IRunPersistence port. Forward writes first, then compare the last successful
snapshot in this invocation with the new snapshot. Observe process activation,
closed-log result/routing, agent waiting and terminal/interrupted changes without
replaying history. Application, Infrastructure, state schema and JSON response
types remain unchanged. No generic event bus or stored event history is needed.

The activation write precedes launch, so say "Activating process (launch pending)"
rather than claiming a child is running. Result/route messages follow a successful
save; failed persistence cannot produce a false durable-transition message.
Completion acceptance is likewise announced only after its authoritative write;
receipt retries remain summaries, not new activity. A read-only status may project
interruption but must not announce a newly saved transition.

Use stderr for newline-delimited, flushed text activity, including redirection.
Keep final summaries on stdout. Include stable run/node/activation identifiers,
not child output or prompts. Use P13 escaping and existing transition bounds;
no timers, spinner, terminal detection or dependencies. Suppress activity for
explicit JSON, preserving its serializer and diagnostic behavior. A closed
activity pipe disables activity without interrupting execution. Slow consumers
may apply normal pipe backpressure; no background/unbounded queue is introduced.

The agreed verification seams remain the published native CLI and public build
entry point. A controlled native barrier proves feedback is observable before
process completion; regression cases cover ordering, idempotency, errors,
interruption, escaping and JSON. Release qualification remains independent.
